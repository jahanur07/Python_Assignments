# Python Assignments

A collection of Python practice assignments used to strengthen programming fundamentals through hands-on problem solving.

## Purpose

Use this repository to organise assignment solutions, practise readable Python and revisit concepts through small programs.

## Learning areas

The exact topics depend on the assignments committed here. Common practice areas include:

- Variables, data types and input/output
- Conditional statements and loops
- Strings and collections
- Functions and recursion
- Modules and built-in libraries
- File handling and exception handling
- Object-oriented programming

## Run a solution

Make sure Python 3 is installed, then run an individual script:

```bash
python path/to/your_file.py
```

Use `python3` instead if that is the command configured on your system.

## Practice workflow

1. Read and understand the problem statement.
2. Plan the logic before coding.
3. Write and run the solution.
4. Test normal, boundary and invalid inputs where applicable.
5. Refactor for clarity and explain the approach.

This repository documents practice work. A topic is complete when its solution is understood and can be explained—not simply when a file has been added.
